Vanilla Minecraft forces you to choose: Fortune *or* Silk Touch, Infinity *or* Mending. Adjustability lets an item hold mutually exclusive enchantments, with one side of each conflict active at a time. Switch which one is active from the Adjust panel.

Supports Minecraft Java **1.21.1** and **26.3** on **Fabric** and **NeoForge**, built from one codebase with Stonecutter. MIT licensed, currently in beta.

![A pickaxe holding both Fortune and Silk Touch, switched in the Adjust panel](https://raw.githubusercontent.com/SafetImamovic/Adjustability/master/docs/public/screenshots/showcase.gif)

## Highlights

- **Automated testing**: 35 GameTests run on both loaders in CI, plus a Fabric client GameTest that drives the real panel.
- **Compatibility tested** with Easy Anvils, JEI, Mouse Tweaks, Enchantment Descriptions, AppleSkin, Enchantment Switch and YACL.
- **Docs site**: guide, cookbook, compatibility notes, a Java API for other mod authors, and generated reference pages.
- This started as my 2024 Forge 1.20.6 prototype, then was rebuilt and finished for modern versions.
