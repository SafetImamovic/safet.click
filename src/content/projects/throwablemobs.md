Pick up any mob, carry it around, and throw it, or catch one mid-air. It runs on both **Fabric** and **NeoForge** for Minecraft Java 26.3 and is MIT licensed.

## Highlights

- Per-mob profiles: each mob type gets its own carry and throw behaviour.
- Behaviours such as the *chicken radar*: a carried chicken panics when a monster is near.
- Releases are automated. Every `v*` tag builds the GitHub Release and publishes the Modrinth versions.

Docs: [safetimamovic.github.io/ThrowableMobs](https://safetimamovic.github.io/ThrowableMobs/)
