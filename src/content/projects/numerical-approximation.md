A teaching-friendly tool for numerical methods: enter data, see each step of the calculation, and compare fits on interactive plots.

- Manual data entry, function expressions, or CSV/JSON uploads.
- MathLive for typing maths, Plotly for the plots.
- Interface in Bosnian and English.
